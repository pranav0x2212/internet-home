Things I've built, mostly around processors, memory and small chips. Everything is on [GitHub](https://github.com/pranav0x2212).

## Herald

A CORDIC-based math coprocessor that adds fast trigonometric and MAC operations to the Arduino Uno. Designed for tapeout on Tiny Tapeout.

[Write-up](/blogs/herald.html) · [Code](https://github.com/pranav0x2212/Herald)

## HADES

A programmable processing-near-memory engine for binary similarity search, designed for Tiny Tapeout. No silicon yet, so every number in the write-up comes from simulation.

[Write-up](/blogs/hades.html) · [Code](https://github.com/pranav0x2212/HADES)

## Tiny Tone

A PWM tone generator peripheral for the TinyQV SoC, written in Bluespec SystemVerilog. My first accepted Tiny Tapeout design.

[Write-up](/blogs/tiny-tone.html) · [Code](https://github.com/pranav0x2212/tiny-tone)

## Aetheron

A minimal RISC-V SoC with a TileLink-lite interconnect and basic peripherals, able to run bare-metal C programs.

[Write-up](/blogs/aetheron.html) · [Code](https://github.com/pranav0x2212/Aetheron)

## Specula

An out-of-order RISC-V RV32I core with basic dynamic scheduling and register renaming. Built for simulation, still a work in progress.

[Code](https://github.com/pranav0x2212/Specula)

## RISCape

A 5-stage pipelined RISC-V processor.

[Code](https://github.com/pranav0x2212/RISCape)

## Aletheia

A memory-centric experimentation framework for exploring processing-near-memory concepts on commodity hardware.

[Code](https://github.com/pranav0x2212/Aletheia)

## prawns-stack

A personal lab of notes, papers and code across hardware and systems.
